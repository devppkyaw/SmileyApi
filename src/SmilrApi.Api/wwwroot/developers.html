API Reference

Integration API

Requires X-Api-Key header. Free tier: 100 req/day · Pro: 10,000 req/day.

Method Path Description
GET /v1/establishments/{cvr} Establishment details + latest inspection
GET /v1/establishments/search Search by name or address (?q=)
GET /v1/establishments/nearby Geo search — pass ?lat= &lng= &radius= (km)
GET /v1/establishments/{cvr}/history Full inspection history for one establishment
POST /v1/webhooks/ Subscribe to score-change notifications for an establishment
GET /v1/webhooks/ List active webhook subscriptions for your API key
DELETE /v1/webhooks/{id} Unsubscribe a webhook

Widget API

No authentication required. Suitable for embedding on any website.

Method Path Description
GET /widget/score Embed badge data by CVR · no auth required

Geo search — getting coordinates

The nearby endpoint requires ?lat= and ?lng=. Here are two ways to get them.

JS Browser Geolocation API 
navigator.geolocation.getCurrentPosition(pos => {
  const { latitude, longitude } = pos.coords;
  fetch(`https://api.smilrhq.dk/v1/establishments/nearby?lat=${latitude}&lng=${longitude}&radius=2`, {
    headers: { 'X-Api-Key': 'YOUR_API_KEY' }
  })
  .then(r => r.json())
  .then(data => console.log(data.results));
});
JS Nominatim — address to coordinates (free, no key) 
// Step 1: convert an address to coordinates using OpenStreetMap Nominatim
const address = encodeURIComponent('Rådhuspladsen 1, Copenhagen');
const geo     = await fetch(`https://nominatim.openstreetmap.org/search?q=${address}&format=json&limit=1`);
const [place] = await geo.json();

// Step 2: use the coordinates with Smilr
const data = await fetch(
  `https://api.smilrhq.dk/v1/establishments/nearby?lat=${place.lat}&lng=${place.lon}&radius=2`,
  { headers: { 'X-Api-Key': 'YOUR_API_KEY' } }
).then(r => r.json());
console.log(data.results);
