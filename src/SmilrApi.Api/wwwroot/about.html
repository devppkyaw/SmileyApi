Smilr

What is Smilr?

Smilr is a service that lets Danish food businesses embed their official Fødevarestyrelsen smiley score directly on their own website — with a single line of code.

Every restaurant, café, and food producer in Denmark is inspected regularly and awarded an official smiley score. That data is public, but displaying it has always required manual effort. Smilr syncs the data daily and gives you a badge that stays up to date automatically.

For developers, Smilr also exposes the full dataset as a clean REST API — no XML parsing, no infrastructure to maintain.
