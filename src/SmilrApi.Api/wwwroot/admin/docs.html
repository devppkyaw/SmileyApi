Internal API Docs

Session-based and admin endpoints. Not exposed to external developers.

Authentication (magic link, session)

Used by the dashboard frontend. All session endpoints read business_id from the server-side session.

MethodPathDescription
POST/v1/business/registerRegister new business — sends verification email
GET/v1/business/verifyEmail verification redirect — sets session cookie
POST/v1/business/loginRequest magic login link
GET/v1/business/login/verifyMagic link verification — sets session cookie
POST/v1/business/logoutClear session
GET/v1/business/meReturn logged-in business profile

API Key management (session)

Lets a logged-in business generate, view, and revoke their own X-Api-Key.

MethodPathDescription
POST/v1/business/apikey/generateGenerate a new API key (rotates existing)
GET/v1/business/apikeyGet current key status — tier, createdAt (key not retrievable)
DELETE/v1/business/apikeyRevoke active API key — returns revokedAt timestamp

Location management (session)

Free tier: limited to one CVR. Pro: unlimited CVRs and individual Navnelbnr lookups.

MethodPathDescription
GET/v1/business/locationsList all locations with last 4 inspection scores
POST/v1/business/locationsAdd single location by Navnelbnr (Pro only)
POST/v1/business/locations/by-cvrAdd all locations for a CVR (free: 1 CVR limit)
DELETE/v1/business/locations/{navnelbnr}Remove a single location
DELETE/v1/business/locations/by-cvrRemove all locations for a CVR

Webhooks (session, Pro only)

Session-based alternative to the API key webhook endpoints — for dashboard users.

MethodPathDescription
POST/v1/business/webhooks/Subscribe to score-change notifications
GET/v1/business/webhooks/List active subscriptions
DELETE/v1/business/webhooks/{id}Unsubscribe

Stripe (session + webhook)

Checkout and portal require session. The webhook validates via Stripe-Signature header.

MethodPathDescription
POST/v1/business/checkoutInitiate Stripe checkout for Pro upgrade
POST/v1/business/portalRedirect to Stripe customer portal
POST/v1/stripe/webhookStripe event handler — signature-validated, no session

Admin (X-Admin-Key header)

Requires X-Admin-Key header matching the Admin:Key config value.

MethodPathDescription
POST/admin/syncTrigger XML sync from Fødevarestyrelsen — runs background job
POST/admin/verifyValidate an Admin key — returns 200 or 401
