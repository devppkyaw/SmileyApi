API Reference

All endpoints require an X-Api-Key header.

Method Path Auth Description
GET /v1/establishments/{cvr} Required Establishment details + latest inspection
GET /v1/establishments/search Required Search by name or address (?q=)
GET /v1/establishments/nearby Required Geo search — pass ?lat= &lng= &radius= (km)
GET /v1/establishments/{cvr}/history Required Full inspection history for one establishment
